# 首页国家订单分布设计

## 目标

在 `wristo-dashboard` 首页新增“国家订单分布”统计，让管理员按指定日期范围查看成功订单数最多的国家及其占比。

## 统计口径

- 仅统计 `purchase_records.status = 1` 且 `is_deleted = 0` 的成功订单。
- 默认日期范围为最近一个月，开始和结束日期均包含在统计范围内。
- 用户选择的日期范围最长为一个月；前后端都校验该限制。
- 支持 Top 5、Top 10、Top 20，默认 Top 10。
- `country_code` 去除首尾空格并转为大写后参与聚合。
- 空值、空字符串以及不符合两位英文字母格式的值统一归入 `Unknown`。
- 每个国家的占比以当前日期范围内全部成功订单数为分母，而不是只以 Top N 订单数为分母。

## 后端设计

在 `wristo-api` 的 purchase 模块新增独立的国家订单统计查询链路：

1. 管理端接口接收 `startDate`、`endDate` 和 `topN`。
2. Service 负责默认值和边界校验：
   - 未传日期时使用最近一个月；
   - 日期倒置或跨度超过一个月时拒绝请求；
   - `topN` 仅允许 5、10、20。
3. Mapper 使用数据库聚合查询：
   - 查询 Top N 国家及订单数；
   - 查询相同条件下的成功订单总数。
4. Service 计算每个国家占全部成功订单的百分比，并返回 `totalOrders`、Top N 列表及 Top N 之外的 `otherOrderCount`。

接口保持管理员权限边界，不复用商家设备统计接口，也不把国家统计耦合进设备统计 DTO。

## 前端设计

新增独立的 `CountryOrderDistribution` 首页组件，并放在“设备型号”统计之后、“应用销售总计”之前。

组件包括：

- 日期范围选择器，默认最近一个月，禁止未来日期并限制最长一个月；
- Top N 下拉选择器，选项为 5、10、20；
- 当前范围的总订单数；
- 左侧环形图；
- 右侧 Top N 表格，展示国家名称、两位国家码、订单数和占全部订单比例。

国家名称通过 `Intl.DisplayNames` 使用中文区域名称解析。无法解析时回退显示国家码；`Unknown` 显示为“未知”。

环形图展示 Top N 国家，并在 `otherOrderCount > 0` 时增加“其他”，保证图表总量等于当前范围内全部成功订单。表格只展示 Top N 国家，不展示“其他”。

## 状态与异常

- 组件自行管理加载、空数据和错误状态，不阻塞首页其他统计组件。
- 请求失败时显示“获取国家订单分布失败”，保留日期和 Top N 选择，允许用户重新触发查询。
- 无订单时显示空图和空表，总订单数为 0。

## 验证

- 后端测试覆盖默认参数、Top N 白名单、最长一个月、Unknown 归并、排序、总订单数和其他订单数。
- 前端执行 `npm run build`，确认类型和生产构建通过。
- 如本地 API 与 Dashboard 可运行，手动检查默认加载、日期限制、Top N 切换、空数据和响应式布局。

## 非目标

- 不增加世界地图。
- 不同步或修复历史订单的国家码。
- 不改动现有设备型号统计。
- 不为国家名称引入第三方国家字典依赖。
