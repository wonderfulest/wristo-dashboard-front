# 商家应用平均下载量设计

## 目标

在后台 `/merchant` 商家列表中增加“应用平均下载量”列，帮助管理员直接查看每个商家单个应用的平均下载表现。

## 展示与计算

- 新列放在“总下载”之后、“操作”之前。
- 前端使用当前行已有的 `totalDownloads` 和 `appCount` 计算，不修改后端接口或数据库。
- 计算公式为 `Math.round(totalDownloads / appCount)`。
- `appCount` 缺失或小于等于 `0` 时显示 `-`，避免除零和无意义结果。
- `totalDownloads` 缺失时按 `0` 参与计算。
- 列宽设置为 `140px`，结果以十进制整数展示。

## 修改范围

仅修改 `wristo-dashboard/src/views/merchant/Merchant.vue`，增加一个小型格式化函数和对应表格列，不调整编辑表单、分页、搜索或接口类型。

## 验证范围

按用户要求不运行测试、构建、浏览器或接口验证；完成后仅检查代码差异，确认计算口径、零应用兜底和列位置符合设计。
